Como os dados são classificados?
✔ Supressão Autorizada (ASV)

Área de alerta sobreposta a uma Autorização de Supressão de Vegetação emitida pelo SINAFLOR+/IBAMA, com status ativo e válida na data de detecção do alerta, no mesmo bioma.

◑ Supressão Regularizada (DERADSA)

Área de alerta sobreposta a uma Declaração de Regularidade Ambiental de Supressão de Vegetação emitida pela SEMARH-PI. Disponível somente para 2024 e 2025.

✘ Irregular / Não Autorizado

Fragmento de alerta sem cobertura por ASV ou DERADSA válidas. A operação deveria ser de diferença geométrica real — não por critério de maioria de área.

⚠ Nota Importante: Os valores exibidos são estimativas baseadas no Índice de Pressão de Ilegalidade (IPI) Proxy — razão área alertada / (alertada + autorizada). A classificação proporcional real requer execução do pipeline Python/GeoPandas com intersecção espacial (gpd.overlay). Resultados servem para triagem e análise exploratória, não para autuação.

"Regularizado" indica que a supressão recebeu uma DERADSA, mas não necessariamente que estava previamente autorizada.
